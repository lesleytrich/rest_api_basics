HTTP Methods

The verbs of the web. These define the action you want to perform on a resource.

GET

SAFE

Retrieves data from the server. Should not affect the state of the resource.

GET /api/users

POST

CREATE

Submits data to the server to create a new resource.

POST /api/users
{ "name": "Alice" }

PUT

REPLACE

Updates a resource by replacing it entirely.

PUT /api/users/1
{ "id": 1, "name": "Bob" }

PATCH

UPDATE

Partially updates a resource (only changes fields sent).

PATCH /api/users/1
{ "role": "admin" }

DELETE

REMOVE

Removes a specific resource from the server.

DELETE /api/users/1

Status Codes

The server's way of telling you what happened. Click a category to explore.

2xx Success

200 OK

Everything worked perfectly.

201 Created

Resource successfully created.

204 No Content

Success, but nothing to return.

3xx Redirection

301 Moved Perm.

Resource moved permanently.

304 Not Modified

Use cached version.

4xx Client Error

400 Bad Request

Invalid syntax or data.

401 Unauthorized

Who are you? Log in.

403 Forbidden

You are logged in, but can't do this.

404 Not Found

Resource doesn't exist.

429 Too Many Req.

Slow down!

5xx Server Error

500 Internal Error

Server crashed/failed.

503 Service Unavail.

Server is overloaded/down.
